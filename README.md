Crumb and Co — Bakery Landing Page

A desktop landing page UI/UX design project for a bakery brand, created in Figma.

Project Overview
Crumb and Co presents bakery products through an elegant visual style, clear content hierarchy, and a warm, inviting design.

Project Objectives
- Design a visually appealing bakery landing page.
- Showcase best-selling products.
- Maintain consistent typography, spacing, and colors.
- Provide clear navigation and contact information.

Tools
- Figma
- GitHub

Project Sections
- Header and navigation
- Hero section
- About section
- Bestselling products
- Bakery process
- Contact and footer
