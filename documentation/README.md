Project Documentation — Crumb and Co

About the Project
Crumb and Co is a bakery landing page UI/UX project focused on creating a clean, elegant, and welcoming online presence for a bakery.

Design Objectives
- Create a clear visual hierarchy.
- Maintain consistent spacing and alignment.
- Use suitable typography and a cohesive color palette.
- Highlight bakery products effectively.
- Make contact information easy to find.

Design Tool
Figma

Deliverables
- Desktop landing page design
- Bakery product showcase
- Project screenshots
- Detailed case study
- Figma design file and prototype, if applicable
