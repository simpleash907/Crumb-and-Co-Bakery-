Crumb and Co — Project Case Study

Project Overview
Crumb and Co is a bakery landing page design created to present bakery products through a warm, inviting, and visually consistent digital experience.

Project Goal
To design an attractive desktop landing page that communicates the bakery's identity, showcases best-selling products, and encourages customers to explore the offerings.

Design Process
1. Project planning and content structure
2. Wireframing and section planning
3. Visual design and typography selection
4. Layout refinement and consistency checks
5. Final design presentation

Key Sections
- Header and navigation
- Hero section with call to action
- About the bakery
- Bestselling products
- Bakery process
- Contact information and footer

Tools Used
